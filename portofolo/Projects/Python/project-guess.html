Number Guessing Game

Project Overview

This is a beginner-friendly Python project using Tkinter. This was one of my first coding projects a simple game where the user guesses a randomized number within a specific range. The game provides feedback on whether the guess is too high or too low, guiding the player until they find the correct answer.

Key Features:

  • Random number generation (1–100)
  • Live feedback (too high / too low)
  • GUI with Entry boxes and Buttons
  • Attempt counter

Technologies Used:

Python, Tkinter

What I Learnt:

  • Core Programming Concepts: Practiced variables, loops, conditionals, and input handling, reinforcing the foundations of programming logic.
  • Randomization: Learned how to use random number generation to create unpredictability and replayability in games.
  • User Interaction: Gained experience designing basic user interaction systems through console inputs and real-time feedback.
  • Debugging and Problem Solving: Built the habit of testing, identifying errors, and iterating to improve the user experience.

Future Improvements:

  • Rebuild the game using a better graphical user interface to make it more engaging and user-friendly.
  • Add difficulty levels (easy, medium, hard) to adjust the range of numbers and number of attempts.
  • Store high scores or best performances locally (e.g., in a text file or database) to encourage replayability.
  • Implement a timer to add a competitive element, challenging players to guess the number within a time limit.
  • Enhance the visual design with better graphics, animations, and sound effects to create a more immersive experience.
  • Add a give up or quit button to end the game early.
