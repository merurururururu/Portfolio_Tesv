Project Overview

This is a Python-based currency converter using Kivy for the interface and the ExchangeRate-API for real-time data.

Key Features:

  • Select base currency
  • Choose multiple target currencies
  • Real-time exchange rates with API
  • Displays top 5 rates
  • Mobile-friendly Kivy UI

Technologies Used:

Python, Kivy, REST API (ExchangeRate-API)
