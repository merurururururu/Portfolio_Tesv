Project Overview

This project is a simple, interactive currency converter app built using Kivy for the GUI and the ExchangeRate-API for real-time currency rates. The app allows users to input:

  • a base currency
  • an amount to convert
  • a list of target currency

It then outputs the converted amounts and also displays the top 5 most valuable currencies relative to the base.

Key Features:

  • Select base currency
  • Choose multiple target currencies
  • Real-time exchange rates with API
  • Displays top 5 rates
  • Mobile-friendly Kivy UI

Technologies Used:

Python, Kivy, Requests, REST API (ExchangeRate-API)

What I Learned

  • Kivy UI Design: Gained hands-on experience with BoxLayout, ScrollView, TextInput, Button, and Label widgets.
  • Working with APIs: Learned how to make HTTP requests and parse JSON data in Python.
  • Data Filtering and Formatting: Practiced converting and formatting numerical data for user display.
  • Error Handling: Implemented defensive programming to catch and display input errors and API issues.

Known Flaws / Limitations

  • API Dependency: Requires a stable internet connection and an API key with valid quota.
  • Basic UI Design: Functional but minimal visual customization—could benefit from better styling and animations.
  • No Offline Mode: App doesn't cache previous rates, so it can't be used offline.
  • No Input Suggestions: Users must manually type currency codes; there's no dropdown or autocomplete.

Future Improvements

  • Better UI/UX Design: Add icons, color themes, and animations for a more polished interface.
  • Autocomplete for Currency Codes: Reduce errors by letting users select currencies from a predefined list.
  • Historical Data: Implement a feature to show currency trends or past rates.
  • Currency Flags or Icons: Visual enhancement to make the app more intuitive.
  • Export to CSV or PDF: Allow users to save their conversions
  • Dark Mode / Light Mode Toggle: Improve accessibility and visual appeal.
  • Multi-Language Support: Expand usability for non-English speakers.
