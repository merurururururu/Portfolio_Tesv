This is my personal portfolio project, designed to showcase both my graphic design and programming work under the unified brand 58.

Overview
This is my personal portfolio project, designed to showcase both my graphic design and programming work under the unified brand 58.
The project includes:
-A custom-coded portfolio site (58.html)
-Individual project pages with in-depth details and links
-An interactive resume that users can explore dynamically
-Downloadable resources (PDF resume, project files)

Features
-58.html (Main Portfolio Page)
-Scrolling banner with a custom tagline
-Project Gallery showcasing both design and development work
-About section with links to the interactive resume and PDF download
-Contact section for getting in touch

Individual Project Pages

Interactive Resume
A web-based resume that allows users to explore my background interactively

Tech Stack
HTML5 / CSS3

Responsive design

How to Use
-Open 58.html in a browser to view the portfolio.
-Click on project thumbnails to explore detailed pages.
-Use the buttons under the About section to either download the PDF resume or explore the interactive one.
